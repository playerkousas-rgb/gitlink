## 如何新增連結

沿用同樣格式，加進對應分類的表格即可：

```md
| [owner/repo](https://github.com/owner/repo) | Xk | 一句話說明用途 |
```

規則：

1. 只收**大型、出名、可當參考資料庫**的 repo（星數多、維護中、非 archived）。
2. 按用途放進分類；找不到合適分類就開新的分類區塊。
3. 連結一律用完整 `https://github.com/owner/repo` 網址。
